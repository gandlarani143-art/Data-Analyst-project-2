Customer Lifetime Value (LTV) Prediction Model

Project Overview

The Customer Lifetime Value (LTV) Prediction Model predicts the future value of customers based on their purchase behavior. It helps businesses identify valuable customers and improve targeted marketing strategies.

Objective

To predict customer lifetime value using machine learning techniques based on purchase history.

Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Random Forest Regressor
- Matplotlib
- Pydroid 3

Project Workflow

1. Create and preprocess customer purchase data.
2. Calculate customer features:
   - Frequency
   - Recency
   - Average Order Value (AOV)
3. Split the dataset into training and testing data.
4. Train a Random Forest Regression model.
5. Predict customer lifetime value.
6. Evaluate the model using MAE and RMSE.
7. Segment customers based on predicted LTV.
8. Generate visualizations and save predictions as a CSV file.

Customer Segmentation

- High Value: LTV greater than or equal to 15,000.
- Medium Value: LTV greater than or equal to 7,000.
- Low Value: LTV below 7,000.

Model Evaluation

The model performance is evaluated using:

- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)

Output

- Customer LTV predictions.
- Customer segmentation.
- LTV visualization graph.
- LTV_Predictions.csv file.

How to Run

1. Install Python and required libraries.
2. Open the Python program in Pydroid 3.
3. Run the program.
4. View the prediction results.
5. Check the generated CSV file.

Conclusion

This project uses Machine Learning to predict Customer Lifetime Value and classify customers into different segments. It helps businesses understand customer purchasing behavior and support targeted marketing decisions.
